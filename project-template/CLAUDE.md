# Adcraft SEO reports workspace

This folder holds generated SEO / GEO / AEO / Local / GBP audit reports, one sub-folder per domain and date.

Whenever the user asks for any kind of SEO, GEO, AEO, local SEO, Google Business Profile or crawl report or audit,
or simply types a website address, use the `seo-report` skill. If the skill is not offered as a slash command,
read `.claude/skills/seo-report/SKILL.md` in this folder (a copy of `~/.claude/skills/seo-report/SKILL.md`) and
follow it exactly. Treat a bare domain or URL typed by the user as `/seo-report <url>`.

Do not modify the skill files from here; they are updated automatically from GitHub.
